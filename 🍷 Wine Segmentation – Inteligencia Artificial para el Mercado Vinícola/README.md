# 🍷 Wine Segmentation – Inteligencia Artificial para el Mercado Vinícola

## 📌 Descripción

Este proyecto aplica técnicas de Aprendizaje No Supervisado (Clustering K-Means) para transformar un conjunto de datos químicos complejos de 178 vinos italianos en una estrategia comercial segmentada. El análisis decodifica el "ADN químico" de los productos (alcohol, flavonoides, intensidad de color, etc.) para identificar nichos de mercado, optimizar precios y diseñar campañas de marketing diferenciadas.
El desarrollo se realizó íntegramente en R, generando resultados validados estadísticamente que permiten pasar de una gestión de inventario genérica a una segmentación de precisión con alto impacto en la rentabilidad.
