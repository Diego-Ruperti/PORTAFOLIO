# 📊 A/B Test – Campañas de Marketing

## 📌 Descripción

Proyecto de análisis estadístico orientado a evaluar el impacto de tres campañas de marketing sobre las ventas de un nuevo producto en una cadena de comida rápida, utilizando datos públicos de Kaggle.
El análisis se desarrolla en R y los resultados se documentan en formatos orientados tanto a negocio como a análisis técnico.

---
## 📁 Contenido del proyecto

- **README.md** → Guía general del proyecto y descripción del contenido de la carpeta.

- **Resumen_Ejecutivo.pdf** → Documento breve orientado a negocio. Presenta el problema, el enfoque analítico, los resultados clave y la recomendación final.

- **Informe_Ejecutivo.pdf** → Documento completo con el análisis detallado, validación de supuestos, resultados estadísticos y conclusiones.

- **AB_Test_Analysis.R** → Código en R utilizado para la preparación de datos, análisis exploratorio, pruebas estadísticas y visualizaciones.

- **Presentacion.pdf** → Presentacion del proyecto con imagenes y conclusiones

- **DATA / WA_Marketing-Campaign.csv** → Conjunto de datos utilizado en el análisis (fuente pública – Kaggle).
