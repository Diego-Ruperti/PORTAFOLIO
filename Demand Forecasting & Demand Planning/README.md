# 📈 Demand Forecasting & Demand Planning

## 📌 Descripción

Proyecto de análisis de series de tiempo orientado a la construcción de un forecast base de ventas y su interpretación para planeación de demanda (S&OP), utilizando datos públicos de Kaggle.  
El proyecto combina preparación de datos en SQL, modelado estadístico en R y una interpretación orientada a la toma de decisiones de negocio.

---
## 📁 Contenido del proyecto

- README.md → Guía general del proyecto y descripción del contenido de la carpeta.

- Resumen_Ejecutivo.pdf → Documento breve orientado a negocio. Resume el problema, el enfoque analítico, los principales hallazgos y las implicaciones para planeación de demanda.

- Informe_Ejecutivo.pdf → Documento completo con el desarrollo del análisis, preparación de datos, modelos de forecast, evaluación de desempeño y conclusiones.

- Script_MySQL_DataCleaning.sql → Script en MySQL para validación, limpieza y agregación mensual de los datos de ventas.

- Script_R-Studio_Forecast.R → Código en R utilizado para el análisis exploratorio, construcción de modelos de forecast, evaluación y visualizaciones.

- Presentacion.pdf → Presentacion del proyecto con imagenes y conclusiones

- DATA / → Carpeta que contiene los archivos CSV utilizados en el proyecto (fuente pública – Kaggle).
